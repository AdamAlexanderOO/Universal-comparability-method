# Universal Comparability Method - Integrated Platform Hub

A unified platform combining 6 distinct projects into a single, modular interface. Each project maintains its individuality while sharing a common graphical interface and infrastructure.

## 🌟 Platform Overview

This is your complete ecosystem dashboard featuring:

- **Universal Comparability Method** - Core comparative analysis engine
- **Light Genesis Core** - Browser-native civilization operating system
- **Ai Vision** - Programmable game engine
- **Light Protocol** - Advanced coding language specification
- **Light Stage One** - Protocol implementation stage
- **Additional Integrations** - Extended functionality modules

## 🔧 API Endpoints

All modules expose REST APIs:

### Universal Comparability Method
- `POST /api/compare` - Run comparison analysis
- `GET /api/results` - Fetch analysis results

### Light Genesis
- `POST /api/simulate` - Run civilization simulation
- `POST /api/diagnose` - System diagnostics
- `POST /api/synthesize-light` - Light protocol synthesis

### AI Vision
- `POST /api/game/init` - Initialize game
- `POST /api/game/command` - Process game command

### Light Protocol
- `POST /api/protocol/validate` - Validate protocol
- `GET /api/protocol/spec` - Get protocol specification

See `/docs/API.md` for complete reference.

## 🔄 Integration Guide

To integrate a new module:

1. Create module folder in `src/modules/`
2. Add module route in `App.tsx`
3. Create module card in dashboard
4. Add documentation
5. Register API endpoints in `server.ts`
6. Add to module navigation

See `/docs/ARCHITECTURE.md` for detailed guide.
